# Crédits

KhopeSpigot est construit à partir du travail de nombreux projets et contributeurs open source.

## KhopeSpigot

KhopeSpigot est maintenu dans le dépôt :

- [ELITEAYOTO/KhopeSpigot](https://github.com/ELITEAYOTO/KhopeSpigot)

Il contient des modifications spécifiques destinées notamment aux besoins du serveur Volkaria.

## PandaSpigot

La base principale de KhopeSpigot est :

- [hpfxd/PandaSpigot](https://github.com/hpfxd/PandaSpigot)

PandaSpigot est un fork de Paper pour Minecraft 1.8.8 axé sur les performances, la stabilité et différentes améliorations de l'API et du réseau.

Une grande partie de l'historique Git de KhopeSpigot provient directement de PandaSpigot. Les auteurs de ces commits restent crédités dans l'historique Git et peuvent donc apparaître automatiquement dans la section **Contributors** de GitHub.

## Paper

PandaSpigot et KhopeSpigot héritent également du travail réalisé par le projet Paper et ses contributeurs.

- [PaperMC](https://github.com/PaperMC)

## Spigot et CraftBukkit

Le projet repose également sur le travail historique de Spigot et CraftBukkit pour l'écosystème serveur Minecraft.

## Contributeurs

Les auteurs des commits historiques conservés dans le dépôt restent crédités grâce aux métadonnées Git originales.

KhopeSpigot ne revendique pas la paternité des modifications provenant de PandaSpigot, Paper, Spigot, CraftBukkit ou d'autres projets upstream.
